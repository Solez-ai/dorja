# DORJA logo assets

The transparent master and web icons retain alpha. iOS/Android installable app icons use the DORJA Paper background `#FBF8F2` because platform app icons should not rely on transparency. Android adaptive icon exports include a transparent foreground and separate background layer.

| File group | Use |
|---|---|
| `dorja-logo-*-transparent.png` | Header mark, marketing, print, in-app identity |
| `ios-app-icon-*.png` | iOS icon set |
| `android-adaptive-*` | Android adaptive icon layers |
| `android-app-icon-*.png` | Android legacy/fallback icon sizes |
| `web-icon-*.png`, `favicon.ico` | Favicon, PWA, browser tabs |
