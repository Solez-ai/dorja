# Dorja Homestation — Rome FIRSO 2026 Submission

## Overview
Dorja Homestation is an innovative real estate technology platform designed for the FIRSO 2026 competition. It combines panoramic room scanning, financial calculations, document management, and relocation services into a single unified application.

## Key Features

### 🏠 Room Scanner
- 360° panoramic room capture with real-time AR guidance
- Gyroscope-based orientation tracking with accelerometer fallback
- Multi-device support: 5+ manufacturers tested
- 12-frame capture sequence with overlap detection
- Stitching engine with 30-second timeout protection

### 💰 Financial Calculator
- Real-time amortization calculations
- Support for variable interest rates
- Historical calculation storage

### 📋 HandoverPassport
- Promise tracking and deadline management
- Encrypted document vault
- Status notifications

### 💬 Chat System
- Persistent message storage
- Delivery confirmation
- Rich text support

### 🌍 Relocation Mode
- 12+ countries in registry
- Visa requirement database
- Location comparison tools

## System Requirements

- **Android**: 11.0+
- **RAM**: 2GB minimum (4GB recommended)
- **Sensors**: Accelerometer + Magnetometer
- **Camera**: f/2.0 or better
